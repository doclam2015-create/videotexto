# Glosa

Transcribe y analiza videos de YouTube, páginas web y archivos propios: transcripción completa con hablantes, enlaces de la descripción y de la pantalla, resumen, capítulos, ideas clave, chat, tarjetas de estudio y exportación (Markdown, SRT, VTT, PDF, Obsidian).

- **iPad / iPhone / web:** https://doclam2015-create.github.io/glosa/ (Safari › Compartir › Añadir a pantalla de inicio)
- **Mac:** `./mac/build.sh` instala Glosa.app (usa yt-dlp para descargar videos de más de 1.000 sitios e iniciar sesión).
- IA: Gemini con tu propia clave gratuita (aistudio.google.com/apikey). Todo se guarda en tu dispositivo.

Uso personal, no comercial.
